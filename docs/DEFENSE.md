# К защите

Суть: соединённые ребром вершины должны иметь разные цвета; цветов нужно как можно меньше. Особь — список номеров цветов.

Штраф оставляет плохую раскраску, но делает её невыгодной. Ремонт непосредственно перекрашивает конфликтующие вершины. Кроссовер не гарантирует допустимость: её обеспечивает ремонт либо отбор по штрафу.

Как доказать оптимум? Первые пять вершин образуют клику: меньше пяти цветов невозможно. Известная 5-раскраска доказывает достижимость.

Почему baseline лучше? Для данного синтетического графа многократный случайно упорядоченный жадный алгоритм оказывается эффективнее используемых ГА. Это результат исследования, а не ошибка измерения.
